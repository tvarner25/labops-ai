# LabOps AI Website

A zero-dependency static landing page for LabOps AI.

## Files

- `index.html` — complete responsive website (HTML + CSS)

## Run it

Open `index.html` in any browser.

## Publish for free

### GitHub Pages
1. Create a GitHub account.
2. Create a new public repository.
3. Upload `index.html`.
4. Go to Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select `main` and `/ (root)`.
7. Save.

### Cloudflare Pages
1. Create a free Cloudflare account.
2. Put `index.html` in a GitHub repository.
3. In Cloudflare Pages, connect the GitHub repository.
4. For a plain HTML site, use no framework/build step and make sure the directory containing `index.html` is the output directory.
5. Deploy.

## Before launch

Change `hello@labops.ai` in `index.html` to your real email address.

Also consider buying a domain such as `labops.ai` later. A custom domain is not required for the first version.
